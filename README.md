## About me

I'm a computer science graduate working as a Research & Data Associate at **Salim Habib University**, with a focus on **data engineering and applied AI**. I build projects around data ingestion, transformation, orchestration, and warehousing, and help students connect data structures and algorithms with practical software systems.

- **Building:** ETL/ELT pipelines, AWS event-driven workflows, and containerized environments with Docker and Airflow.
- **Exploring:** Generative AI, agentic systems, and their integration into automated workflows.
- **Interested in collaborating on:** Data platforms, intelligent automation, and computer vision projects.
- **Happy to discuss:** Snowflake, CDC, SCD Type 2, AWS pipelines, Docker Compose, and YOLO object detection.
- **Open to:** Data engineering opportunities and meaningful technical collaborations.
